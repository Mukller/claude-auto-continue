Критичный фикс: CLI/headless был сломан с v3.13.1.

## Причина
Два последовательных вызова `_acquire_single_instance()` внутри `run_headless()`:
- первый создавал мьютекс и возвращал True
- второй видел `ERROR_ALREADY_EXISTS` и возвращал False → exit 3

## Следствие
**Каждый headless запуск с v3.13.1 падал с exit 3**, включая `--now`, `--at`, `--interval` — вся CLI функциональность из #17 не работала в собранных релизах.

## Фикс
Удалён дублирующий вызов; остаётся один — в начале функции.

## Проверено
`--headless --now --profile cursor` → exit 0, профиль применяется.
